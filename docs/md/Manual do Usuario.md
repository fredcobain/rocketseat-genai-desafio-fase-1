---

## ✅ Objetivo

Este manual explica passo a passo como utilizar o Intelliway Headshot Generator para gerar imagens profissionais usando IA.

---

## ✅ Requisitos

- Uma foto com o rosto visível e boa qualidade
- Conexão à internet
- Navegador atualizado (Chrome, Firefox, Edge, Safari)

---

## ✅ Passo a passo

### ✅ 1. Acessar o sistema
Entre no link acima. A tela inicial exibirá o botão **Carregar uma foto**.

### ✅ 2. Carregar a foto
- Clique em **Carregar uma foto**
- Escolha uma imagem do seu dispositivo
- Aguarde a pré-visualização aparecer
- Se quiser trocar, clique em **Trocar Foto**

### ✅ 3. Gerar os headshots
- Clique em **Gerar Headshots**
- Aguarde alguns segundos enquanto a IA processa sua imagem

### ✅ 4. Visualizar resultados
Após o processamento, serão exibidas 3 imagens profissionais.

Cada imagem possui:
- ⬇ **Download**
- ✨ **Aprimorar imagem**

### ✅ 5. Aprimorar imagem (opcional)
Clique no ícone de varinha mágica e escreva instruções como:
- “fundo de escritório moderno”
- “terno azul”
- “mais iluminação”
- “traje corporativo formal”

A IA gera uma nova versão aprimorada.

### ✅ 6. Baixar a imagem
Clique no ícone de download para salvar a foto em alta resolução.

### ✅ 7. Começar de novo
Para reiniciar o processo com outra foto, clique em **Começar de Novo**.

---

## ✅ Dicas para melhores resultados

- Fundo neutro
- Boa iluminação
- Rosto centralizado
- Sem objetos cobrindo o rosto
